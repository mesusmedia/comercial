# Painel Comercial L3M

Dashboard de análise de funil comercial para ~30 clientes.

## Estrutura

- `index.html` — Painel web (HTML/JS/CSS puro)
- `specs/agente-analista-comercial.md` — Spec do agente de análise automatizada

## Deploy

Automatico via Vercel a cada push no `main`.

## Stack

- HTML + CSS + JS vanilla
- Tema dark/light
- Dados populados via n8n + Google Sheets API
